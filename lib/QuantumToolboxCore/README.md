# QuantumToolboxCore.jl

[![](https://img.shields.io/badge/docs-stable-blue.svg)](https://qutip.github.io/QuantumToolbox.jl/stable/resources/api#doc-API:QuantumToolboxCore) [![](https://img.shields.io/badge/docs-dev-blue.svg)](https://qutip.github.io/QuantumToolbox.jl/dev/resources/api#doc-API:QuantumToolboxCore)

`QuantumToolboxCore` is a lightweight, low-level package that provides the core data structure and utilities shared across the [QuantumToolbox.jl](https://github.com/qutip/QuantumToolbox.jl) ecosystem.

> [!NOTE]
> This package is re-exported by [QuantumToolbox.jl](https://github.com/qutip/QuantumToolbox.jl).
